# Пакеты документов (ContractDocuments/packages)

Структура рефакторинга раздела «Оформление договоров».

## Слои

- **`config/`** — реестр направлений (`packageDirectionRegistry.ts`): семейство, вкладки, шаблоны, настройки.
- **`pages/`** — `PackageDocumentEditorPage`, `ContractsListPage`.
- **`directions/repair/`** — форма, платежи, анкеты/CRM-синхронизация.
- **`templates/`** — резервные HTML-шаблоны документов (ремонт, окна, двери).
- **`shared/`** — общий UI редактора (табы, hub, hooks, editor).
- **`directions/windows/`**, **`directions/doors/`** — вкладка «Спецификация», Д/с, стоимость, печать пакета.
- **`directions/repair/estimates/RepairFinalEstimateTab`** — вкладка «Итог. смета» (только Ремонт).
- **`shared/editor/ProductSpecificationTab`** — вкладка «Спецификация» для товарных направлений.

Утилиты без привязки к направлению — в `../shared/`:

- `applyTemplate`, `printDocument` — рендеринг и печать
- `typography/` — типографика шаблонов договоров (заголовки, списки, реквизиты, разрывы страниц)
- даты, суммы прописью

## Семейства

| Семейство       | Направления             | Особенности                       |
| --------------- | ----------------------- | --------------------------------- |
| `REPAIR_LIKE`   | Ремонт                  | Смета, акт начала, итог. смета    |
| `PRODUCT_LIKE`  | Окна, Двери             | Счёт-заказ, спецификация, памятка |
| `UNIMPLEMENTED` | Потолки, Жалюзи, Мебель | Заглушка в реестре                |

## Legacy

Код в `../repair/` постепенно истончается; новые модули добавляются сюда.
Старые пути re-export'ятся для совместимости.
