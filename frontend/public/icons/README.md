# Иконки PWA (установка на главный экран)

Для корректного отображения при установке на смартфон добавьте сюда:

- **icon-192.png** — 192×192 px
- **icon-512.png** — 512×512 px

Формат PNG. Можно сгенерировать из `favicon.svg` (например, через [realfavicongenerator.net](https://realfavicongenerator.net) или ImageMagick).  
Пока файлов нет, браузер может использовать `favicon.svg` или стандартную иконку.
