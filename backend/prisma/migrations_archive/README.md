# Архив старых миграций

Эти папки — ранее применённые миграции. Они перенесены сюда при наведении порядка в миграциях (февраль 2026).

Текущая история миграций: одна базовая миграция `20260101_000000_baseline` в `prisma/migrations`, которая описывает полную схему БД. Она помечена как применённая к существующей базе через `prisma migrate resolve --applied 20260101_000000_baseline`.

Новые изменения схемы добавляйте через `npx prisma migrate dev --name описание_изменения`.

Отдельные `.sql`-скрипты (add_size_and_opening_side.sql и др.) — ручные правки, не входящие в цепочку Prisma Migrate.
