# Установка приложения на смартфон (PWA и варианты)

## Текущая реализация: PWA

Проект настроен как **Progressive Web App (PWA)**. Пользователь может установить сайт на главный экран смартфона без магазинов приложений.

### Как установить (для пользователя)

- **Android (Chrome/Edge):** откройте сайт → меню (⋮) → «Установить приложение» / «Добавить на главный экран».
- **iOS (Safari):** откройте сайт → кнопка «Поделиться» → «На экран „Домой“».

### Что уже сделано

- **Манифест** `frontend/public/manifest.webmanifest`: название, иконки, `display: standalone`, цвет темы.
- **Мета-теги** в `layout.tsx`: `manifest`, `theme-color`, `apple-mobile-web-app-capable`, viewport.
- **Иконки:** в манифесте указаны `favicon.svg` и пути `/icons/icon-192.png`, `/icons/icon-512.png`. Для лучшего отображения на Android добавьте в `frontend/public/icons/` PNG 192×192 и 512×512 (см. README в этой папке).
- **Сервис-воркер** (`public/sw.js`): StaleWhileRevalidate для API товаров и каталога — быстрый показ из кэша, обновление в фоне.
- **Попап «Доступна новая версия»**: ненавязчивый баннер внизу экрана с кнопками «Обновить» и «Позже» при выходе нового релиза.

### Стратегия обновления

| Элемент | Стратегия |
|---------|-----------|
| API `/api/v1/products/*`, `/api/v1/home/*` | **StaleWhileRevalidate** — сразу показываем из кэша (до 24 ч), параллельно обновляем данные |
| Новая версия приложения | Баннер «Доступна новая версия. Обновить?» — пользователь решает, когда применить обновление |

При каждом деплое в `sw.js` инжектируется новая версия (build script), браузер обнаруживает изменения и предлагает обновить.

### Требования к размещению

- Сайт должен открываться по **HTTPS** (на production это уже так). Service Worker работает только по HTTPS (или localhost).

## Варианты развития

| Вариант | Описание | Когда имеет смысл |
|--------|----------|-------------------|
| **Только PWA** (текущее) | Установка из браузера на главный экран. | Достаточно для большинства случаев: один код, нет модерации магазинов. |
| **TWA (Android)** | Обёртка над PWA для публикации в **Google Play**. Пользователь ставит приложение из магазина, внутри открывается ваш сайт. | Нужно присутствие в Google Play без отдельной нативной разработки. |
| **Capacitor** | Упаковка веб-приложения в нативное приложение для **App Store** и **Google Play**. Один код (Next.js), сборка под iOS/Android. | Нужны оба магазина; возможна интеграция с камерой, push и т.д. |

### TWA (Trusted Web Activity) для Google Play

- Инструмент: [Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap) или [PWA Builder](https://www.pwabuilder.com/).
- На вход — URL вашего PWA и иконки; на выход — AAB/APK для загрузки в Play Console.
- Подходит, если важно быть в маркете Android, но не хочется писать отдельное приложение.

### Capacitor (App Store + Google Play)

- [Capacitor](https://capacitorjs.com/) упаковывает веб-приложение в нативную оболочку.
- Для Next.js обычно собирают статический экспорт (`output: 'export'`) или отдают в WebView уже развёрнутый сайт.
- Позволяет добавить плагины (push, камера, файлы) и публиковать в оба магазина с одной кодовой базой.

---

Итог: **текущей PWA достаточно для установки на смартфон из браузера.** При необходимости публикации в магазинах используйте TWA (Android) или Capacitor (iOS + Android).
