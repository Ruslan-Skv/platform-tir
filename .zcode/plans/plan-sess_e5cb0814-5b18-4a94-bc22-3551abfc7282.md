# Новый раздел «Натяжные потолки» (/stretch-ceilings)

## Контекст

На публичном сайте нужен раздел «Натяжные потолки» по образцу раздела «Окна» (`/windows`): полный вертикальный срез (таблицы → backend-модуль → API → публичная страница → админка → RBAC → сид), всё управление из админки. По итогам анализа конкурентов (5element-potolki.ru, натяжные-потолки24.рф, fis51.ru) в раздел добавляются два блока, которых нет у «Окон»: **интерактивный калькулятор стоимости** (конверсионное ядро у всех конкурентов) и управляемые **FAQ + этапы работы**. Заодно чинится битая ссылка в футере («Потолки» → `/ceilings` даёт 404) и пункт меню хедера меняется с каталога на раздел.

Паттерн копируется 1:1 с окон (`backend/src/admin/windows/`, `frontend/src/views/windows/ui/WindowsPage/`, `frontend/src/views/admin/Content/Windows/`, `frontend/src/shared/api/windows/`).

## Структура публичной страницы (сверху вниз)

1. Хлебные крошки «Главная → Натяжные потолки»
2. **Hero** — заголовок/подзаголовок/описание/картинка из админки; заметки «Бесплатный замер / Монтаж за 1 день / Гарантия до 15 лет / Без предоплаты»
3. **Каталог фактур** — табы производителей полотен (MSD, Bauf, Pongs, Descor…) → карточки фактур (тип: матовая/глянцевая/сатиновая/тканевая; ширина полотна; характеристики; преимущества; цена ₽/м²; видео через `VideoPlayer`)
4. **Таблица сравнения фактур** — колонки включаются флагами из админки (тип, ширина, цена, страна)
5. **Калькулятор** — ползунки (площадь 1–100 м², периметр м.п., углы 4–16, светильники 0–40, трубы 0–10), выбор фактуры (цена м² берётся из активных фактур каталога), чекбоксы-опции (монтаж люстры, закладная под карниз); живой пересчёт: `площадь×фактура + периметр×багет + (углы−4)×N + светильники×N + трубы×N + опции`, минимум от `calcMinOrder`; кнопка → открытие `quoteModal` с деталями расчёта в комментарии
6. **Этапы работы** — 5–6 шагов, редактируются в админке
7. **FAQ** — аккордеон, редактируется в админке; + JSON-LD FAQPage для SEO
8. **CTA-блок** — фон/кнопки из админки, открывает `measurementModal`/`quoteModal` (копия `WindowsCtaBlock`)

## Модели данных (`backend/prisma/schema.prisma`, рядом с моделями окон ~стр. 1695)

- **`CeilingManufacturer`** → `ceiling_manufacturers` — аналог `WindowBrand`: name, slug (unique), logoUrl, country, description, sortOrder, isActive, `fabrics CeilingFabric[]`
- **`CeilingFabric`** → `ceiling_fabrics` — аналог `WindowProfileSystem`: manufacturerId (FK cascade + index), name, slug (unique), `textureType` (строка: матовая/глянцевая/сатиновая/тканевая/…), tagline, description, imageUrl, videoUrl, **width** (строка: «до 3,2 м», «до 5,1 м бесшовное»), priceFrom (Int?, ₽/м²), characteristics (Json, пары label/value), advantages (String[]), badge, sortOrder, isActive
- **`StretchCeilingsPageBlock`** → синглтон `id='main'` — аналог `WindowsPageBlock`: hero + SEO поля; comparison (Show/Title/Note + флаги 4 колонок); CTA (BackgroundColor/Image/Fit/ImageOpacity/TextColor/ShowButtons); **калькулятор**: calcShow, calcTitle, calcNote, calcPricePerMeterBaget, calcPricePerCorner, calcPricePerLight, calcPricePerPipe, calcLightOptionPrice, calcCorniceOptionPrice, calcMinOrder (Int); **faq Json** ([{question,answer}]), **steps Json** ([{title,description}])

## Backend

- Миграция `backend/prisma/migrations/<ts>_add_stretch_ceilings_section/migration.sql` — 3 таблицы
- `backend/src/admin/stretch-ceilings/` (регистрация в `admin.module.ts`):
  - `stretch-ceilings-public.controller.ts` — `GET /api/v1/stretch-ceilings` (no-store) → `{ settings, manufacturers:[{..., fabrics:[]}] }`
  - `stretch-ceilings.controller.ts` — `@Controller('admin/stretch-ceilings')`, `JwtAuthGuard` + `Roles('ADMIN','CONTENT_MANAGER')`: `POST upload` (multer → `uploads/stretch-ceilings`), CRUD manufacturers, CRUD fabrics (`?manufacturerId=`), `GET/PATCH settings`
  - `stretch-ceilings.service.ts` — по образцу `windows.service.ts` (`emptyToNull`, upsert настроек по `id:'main'`, проверка уникальности slug)
  - `dto/` — 6 файлов (create/update manufacturer, create/update fabric с `FabricCharacteristicItemDto`, update-settings c `@Min/@Max` на opacity и ценами калькулятора)
- RBAC: `backend/src/admin/admin-access/resources.config.ts` + `role-default-resources.config.ts` — ресурс `admin.content.stretch-ceilings`

## Сид (идемпотентный, как `seed-windows.ts`)

- `backend/prisma/seed-stretch-ceilings.ts` + `data/stretch-ceilings-section.json` (+ скрипт в `backend/package.json`): настройки (title «Натяжные потолки», цены калькулятора, 8 FAQ, 6 этапов), 5 производителей (MSD, Bauf, Pongs, Descor, Cerutti) с 2–3 фактурами каждый, обновление `NavigationItem` «Натяжные потолки» → `/stretch-ceilings` и `FooterLink` «Потолки» → `/stretch-ceilings` в БД

## Порядок работ

1. Prisma-модели + миграция 2. Backend-модуль + DTO + RBAC 3. Сид + прогон 4. API-слой фронтенда 5. Публичная страница (включая калькулятор) 6. Админка 7. Константы навигации/футера 8. Сборка и сквозная проверка

## Верификация

- `npx prisma migrate dev` (создание таблиц) → сид → `GET /api/v1/stretch-ceilings` возвращает данные
- Сборка frontend (`npm run build`) без ошибок
- Dev-серверы: `/stretch-ceilings` рендерится с фолбэком и с данными API; калькулятор пересчитывает цену, кнопки открывают модалки; `/admin/content/stretch-ceilings` — вход под ролью CONTENT_MANAGER/ADMIN, правка настроек/фактур отражается на публичке после ISR (60 с) или клиентского refresh; пункт меню и футер ведут на раздел без 404
