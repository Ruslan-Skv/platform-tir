# Новый раздел «Расчётники мастеров» — ведомости авансов мастеров

## Суть

Новый раздел верхнего уровня сайдбара `/admin/installer-advance-sheets` (лейбл «Расчётники мастеров», ресурс `admin.crm.installer-advance-sheets`). Поток:

1. **Ведущий специалист / бригадир** создаёт ведомость: один мастер (из справочника `InstallerMaster`) + 1–10 строк «договор → сумма» (договор — поиск через существующий `PackageOrderSearch`). Создателю доступна печать ведомости для расписки мастера.
2. **Суперадмин** в карточке ведомости: отмечает выплату построчно или всю ведомость разом (дата + способ наличные/банк); по строке может написать вопрос (мини-переписка с ВС); может отменить ошибочную выплату.
3. При отметке «выплачено» в транзакции создаётся запись в существующей таблице `contract_document_package_installer_advances` (журнал авансов) со ссылкой на строку ведомости — она **автоматически** появляется и в журнале авансов договора, и в разделе «Расчёт мастеров» `/admin/installer-settlements`, т.к. оба читают эту таблицу. Отмена выплаты удаляет запись из журнала.

## 1. База данных (backend/prisma/schema.prisma + миграция)

Новые enum и модели (стиль — как `SalarySettlement` / `ContractDocumentPackageInstallerAdvance`):

```prisma
enum InstallerAdvanceSheetItemStatus { PENDING  QUESTION  PAID }

model InstallerAdvanceSheet {          // installer_advance_sheets
  id, number Int @unique @default(autoincrement())  // «Ведомость № 42»
  installerId -> InstallerMaster (Restrict)
  note Text?, createdById -> User (SetNull), createdAt, updatedAt
  items InstallerAdvanceSheetItem[]
}

model InstallerAdvanceSheetItem {      // installer_advance_sheet_items
  id, sheetId (Cascade), packageId -> ContractDocumentPackage (Restrict)
  amount Decimal(12,2), status (PENDING|QUESTION|PAID)
  paidAt Date?, paymentMethod CASH|BANK?, paidById -> User?
  comments InstallerAdvanceSheetItemComment[]
}

model InstallerAdvanceSheetItemComment {  // мини-переписка по строке
  id, itemId (Cascade), authorId -> User (SetNull), body Text, createdAt
}
```

В `ContractDocumentPackageInstallerAdvance` добавляется nullable `sheetItemId` (FK, SetNull, +индекс) — трассировка «строка ведомости → запись журнала» и безопасная отмена. Обратные relation-поля добавляются на `User`, `InstallerMaster`, `ContractDocumentPackage`.

Миграция: `npx prisma migrate dev --create-only -n installer_advance_sheets` (если локальная БД недоступна — эквивалентный SQL вручную в `backend/prisma/migrations/<ts>_installer_advance_sheets/migration.sql`).

Переходы статусов строки: PENDING→PAID (выплата), PENDING→QUESTION (вопрос суперадмина), QUESTION→PENDING («снять вопрос» / автоматически при выплате), PAID→PENDING (отмена выплаты).

## 2. Бэкенд — новый модуль `backend/src/admin/installer-advance-sheets/`

`controller + service + module + dto`, регистрация в `admin.module.ts`. Контроллер `@Controller('admin/installer-advance-sheets')`, `@UseGuards(JwtAuthGuard, RolesGuard)`; класс — чтение для CRM_ROLES (как у installer-settlements); мутации перекрываются на методе:

- `GET /` — список с фильтрами (статус: ожидают/с вопросами/выданы, installerId, период, search, пагинация); агрегаты по строкам (всего/выплачено/вопросы).
- `POST /` — создание {installerId, note?, items:[{packageId, amount}]} — роли `SUPER_ADMIN, BRIGADIER, LEAD_SPECIALIST_FURNITURE, LEAD_SPECIALIST_WINDOWS_DOORS`. Валидации: ≥1 строка, без дублей packageId, amount > 0.
- `GET /:id` — деталка: ведомость + строки с данными договоров (номер из `formData->contract.number`, заказчик, адрес — как в `searchPackages`) + переписка + ссылка на запись журнала.
- `PATCH /:id` — редактирование (замена строк/мастера/примечания): менять можно только PENDING/QUESTION-строки; менять мастера — только если нет PAID-строк.
- `DELETE /:id` — только если нет PAID-строк.
- `POST /:id/items/:itemId/pay` {paidAt, paymentMethod} — `@Roles('SUPER_ADMIN')`: в `$transaction` создаёт запись в `contract_document_package_installer_advances` (installerName-снапшот, note «Ведомость №N от D», sheetItemId, лимит 300/договор как в существующем сервисе) + строка → PAID.
- `POST /:id/pay-all` {paidAt, paymentMethod} — то же для всех PENDING/QUESTION строк.
- `POST /:id/items/:itemId/unpay` — SUPER_ADMIN: удалить связанную запись журнала, строка → PENDING.
- `POST /:id/items/:itemId/comments` {body} — SUPER_ADMIN, BRIGADIER, LEAD_SPECIALIST_*; комментарий суперадмина по PENDING-строке переводит её в QUESTION.
- `POST /:id/items/:itemId/resolve-question` — SUPER_ADMIN: QUESTION→PENDING.

Регистрация доступа: `admin-access/resources.config.ts` (id/label/path), `admin-access/role-default-resources.config.ts` — ресурс по умолчанию только BRIGADIER, LEAD_SPECIALIST_FURNITURE, LEAD_SPECIALIST_WINDOWS_DOORS (SUPER_ADMIN видит всё неявно; остальным — только через «Доступ»), маппинг маршрута в `common/config/admin-api-route-resources.config.ts` по образцу `admin/installers`.

## 3. Фронтенд

- **API-клиент**: `frontend/src/shared/api/crm/admin-installer-advance-sheets.ts` (типы + функции поверх `apiFetch`, по образцу `admin-installer-settlements.ts`).
- **Раздел**: `frontend/src/views/admin/CRM/InstallerAdvanceSheets/` в структуре раздела (Page/PageView/hooks/modals/constants, CSS-модули по образцу InstallerSettlements):
  - **Список** — фильтры-чипы статуса, селект мастера, период, поиск; таблица: № ведомости, дата, мастер, строки (выдано/всего), сумма всего/выплачено, статус, автор; действия «Открыть», «Печать».
  - **Создание** (`/admin/installer-advance-sheets/new`) — общий компонент-форма: мастер (справочник), строки `PackageOrderSearch` + сумма (динамические 1–N), примечание.
  - **Деталка** (`[id]`) — та же форма в режиме правки для ВС/бригадира (только неотоваренные строки); для суперадмина: построчные «Выдать»/«Отменить выплату»/«Вопрос» + «Выдать все оставшиеся» (дата+способ); мини-переписка раскрывается под строкой; статусные бейджи.
- **Маршруты**: `app/admin/installer-advance-sheets/page.tsx`, `new/page.tsx`, `[id]/page.tsx` (паттерн dynamic import + ssr:false + PageSuspenseFallback).
- **Печать**: `print/installerAdvanceSheetPrint.ts` на базе `views/admin/ContractDocuments/core/printDocument.ts` (`printDocumentHtml` + `downloadDocumentPdf`): шапка «Ведомость №__ от __», мастер, таблица строк (№ / договор / заказчик-адрес / сумма), итог, подписи «Выдал ___ / Получил (мастер) ___». Кнопки «Печать» и «PDF» в деталке и списке.
- **Сайдбар и ресурсы**: запись в `widgets/admin/Sidebar/AdminSidebar.tsx` (после «Расчёт мастеров», иконка 💵), `shared/config/admin-resources.ts`, `shared/config/admin-resource-tree.ts` (без родителя — верхний уровень).
