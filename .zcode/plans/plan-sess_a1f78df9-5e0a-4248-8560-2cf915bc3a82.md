# Кнопка «Создать ведомость» в план-графике + перенос формы ведомости в модалку

## Context
На `/admin/crm/repair-schedules` (План-график ремонта) у каждого договора в колонке «Действия» нужна кнопка-иконка «Создать ведомость», открывающая модалку с формой ведомости, предзаполненной договором и мастером из строки. Параллельно переносим форму создания ведомости (сейчас отдельная страница `/admin/installer-advance-sheets/new`) в модалку: «+ Ведомость» на «Расчётниках мастеров» тоже будет открывать модалку, а старый адрес `/new` — редиректить на список. После создания — остаёмся на странице с уведомлением (решение пользователя). Бэкенд не меняется: `POST /admin/installer-advance-sheets` и `GET /package-balance` уже существуют.

## Изменения (только frontend)

### 1. Предзаполнение формы (create-режим)
`frontend/src/views/admin/CRM/InstallerAdvanceSheets/shared/InstallerAdvanceSheetForm.tsx`
- Новые опциональные пропсы: `initialInstallerId?: string` и `initialItems?: Array<{ packageId: string; label: string }>` (учитываются только без `sheet`, т.е. при создании).
- В `useState`-инициализаторах: `installerId = sheet?.installer.id ?? initialInstallerId ?? ''`; строки — из `initialItems` c `amount: ''` (формат label тот же, что в edit-режиме: `[contractNumber, customerName].filter(Boolean).join(' — ') || 'Договор без номера'`).

### 2. Новая модалка создания
Новый файл `frontend/src/views/admin/CRM/InstallerAdvanceSheets/shared/InstallerAdvanceSheetCreateModal.tsx` (+ экспорт из `index.ts`)
- Обёртка над shared `Modal` (`@/shared/ui/Modal`): `size="lg"`, `showCloseButton`, заголовок «Новая ведомость авансов», внутри — `InstallerAdvanceSheetForm mode="create"`.
- Пропсы: `isOpen`, `onClose`, `onCreated?: (sheet: { id: string; number: number }) => void`, `installerId?: string`, `items?: Array<{ packageId: string; label: string }>`.
- При открытии грузит справочник мастеров через `getInstallers()` (паттерн из `hooks/useInstallerAdvanceSheetCreatePage.ts`, логика переезжает сюда); отправка — `createInstallerAdvanceSheet(values)` → `onCreated(created)` и закрытие; ошибки показываются внутри формы (уже умеет).
- Рендер у вызывающих условный (`{ctx ? <Modal/> : null}`) — ремоунт сбрасывает состояние формы между открытиями.

### 3. Кнопка в колонке «Действия» план-графика
`frontend/src/views/admin/CRM/RepairSchedules/list/RepairSchedulesGroupedList.tsx`
- Новые пропсы: `canCreateAdvanceSheets: boolean`, `onOpenAdvanceSheet: (item: RepairScheduleProject) => void`.
- В `renderActions` (после кнопки «Заказ-наряды») и в мобильной карточке `renderMobileCard`: при `packageId && canCreateAdvanceSheets` — `AdminTableIconButton` с `aria-label`/`title` «Создать ведомость» и иконкой heroicons `BanknotesIcon` (`@heroicons/react/24/outline` — уже есть в проекте). `COL_SPAN` не меняется.

### 4. Связка на странице план-графика
- `list/RepairSchedulesPageView.tsx`: state `advanceSheetItem: RepairScheduleProject | null`; условный рендер модалки (паттерн как у `PackageWorkOrdersHubListModal`, строки 363-370); prefill — `installerId={item.installerId ?? undefined}` и одна строка договора; `onCreated` → `flashSuccess('Ведомость № X создана')` + `void refresh()` (обновит колонку З/п) + закрытие.
- `list/hooks/useRepairSchedulesPage.ts`: добавить в модель `canCreateAdvanceSheets = isIasSheetAuthor(user?.role)` (`user` уже берётся через `useAuth()`, строка 83; `isIasSheetAuthor` — из `../..../InstallerAdvanceSheets/shared/installer-advance-sheets-page.constants`).

### 5. «Расчётники мастеров»: «+ Ведомость» открывает модалку
`frontend/src/views/admin/CRM/InstallerAdvanceSheets/list/InstallerAdvanceSheetsPageView.tsx`
- Local state `createOpen`; заменить `Link href="/new"` на кнопку `onClick={() => setCreateOpen(true)}` (стиль кнопки тот же `cdChrome.contractsListHeaderAddBtn`, `data-admin-mutation`).
- Рендер `{createOpen ? <InstallerAdvanceSheetCreateModal isOpen …/> : null}` без предзаполнения; `onCreated` → `void refresh()` + сообщение «Ведомость № X создана» через существующий banner `message`.

### 6. Редирект /new
`frontend/src/app/admin/installer-advance-sheets/new/page.tsx` — заменить содержимое на серверный `redirect('/admin/installer-advance-sheets')` из `next/navigation`.

### 7. Удаление ненужного кода страницы создания
- Удалить: `views/admin/CRM/InstallerAdvanceSheets/create/` (обa файла) и `views/admin/CRM/InstallerAdvanceSheets/hooks/useInstallerAdvanceSheetCreatePage.ts`.
- Обновить баррель `views/admin/CRM/InstallerAdvanceSheets/index.ts` (убрать экспорт `InstallerAdvanceSheetCreatePage`).

## Проверка
1. `npm run type-check` и `npm run lint` в `frontend/`.
2. `npm run dev` + браузерная проверка (browser-use): в план-графике у строк с пакетом есть иконка «Создать ведомость» (для ролей SUPER_ADMIN/BRIGADIER/LEAD_SPECIALIST_*, скрыта для остальных); клик открывает модалку с предзаполненными мастером и строкой договора с подсказкой остатка з/п; создание → уведомление и обновление списка. На «Расчётниках мастеров» «+ Ведомость» открывает пустую модалку; `/new` редиректит на список. Если авторизоваться в админке автоматически не получится — дам чек-лист для ручной проверки.
